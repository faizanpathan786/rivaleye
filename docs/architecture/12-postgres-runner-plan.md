## 3. Environment Configuration

### New Env Var

```
REPORT_PIPELINE_ENGINE=postgres | inngest
```

### Behavior

**In API:**
- If missing, default to `postgres` locally (check via `process.env.NODE_ENV || "development"`).
- If set to `postgres`:
  - Call expandKeywords() **before** creating report row (keep keywords safe)
  - Insert report + Reddit source job in one transaction
  - Do **not** call inngest.send()
- If set to `inngest`:
  - Keep old flow (expandKeywords → inngest.send all platforms)

**In Worker:**
- Read once at startup: `const engine = process.env.REPORT_PIPELINE_ENGINE ?? "postgres"`
- If postgres: start pg-runner polling
- If inngest: start existing inngest event listeners

### Validation

```typescript
const validEngines = ["postgres", "inngest"];
const engine = process.env.REPORT_PIPELINE_ENGINE ?? "postgres";
if (!validEngines.includes(engine)) {
  throw new Error(
    `Invalid REPORT_PIPELINE_ENGINE: ${engine}. Must be one of: ${validEngines.join(", ")}`
  );
}
```

## 4. Report Creation Flow (REPORT_PIPELINE_ENGINE=postgres)

### createReport Service

```
1. Validate input
2. Call expandKeywords() BEFORE creating anything
3. db.transaction(async (tx) => {
     a. Insert reports row (status=queued, stage=queued)
     b. Insert report_platform_jobs for reddit only (status=queued, stage=queued, run_after=now())
   })
4. Return { id: reportId }
```

**Important:** If expandKeywords fails, the entire operation fails before any DB writes. This avoids orphan reports.

### Keyword Expansion Alternatives

**Option A (Prefer):** Expand before transaction.
- Pro: Fail fast if LLM unavailable.
- Con: If report creation is retried, keywords are re-expanded (inefficient but idempotent).

**Option B:** Store keywords in job payload.
- Pro: Deferred expansion if needed later.
- Con: More complex; requires job to know how to expand.

**Recommendation:** Use Option A. It's simpler and matches the current architecture (keywords are request-scoped, not job-scoped).

### `packages/worker/src/pg-runner/fan-in.ts`

```typescript
export async function fanInCheck(reportId: string) {
  await db.transaction(async (tx) => {
    // Advisory lock
    await tx.execute(sql`SELECT pg_advisory_xact_lock(hashtext(${reportId}))`);
    
    // Check all source jobs
    const jobs = await tx
      .select({ status: report_platform_jobs.status })
      .from(report_platform_jobs)
      .where(eq(report_platform_jobs.report_id, reportId));
    
    // If not all terminal, exit
    const allTerminal = jobs.every(j => ["completed", "failed"].includes(j.status));
    if (!allTerminal) return;
    
    // Check synthesis_jobs doesn't have a row yet
    const existing = await tx
      .select({ id: synthesis_jobs.id })
      .from(synthesis_jobs)
      .where(eq(synthesis_jobs.report_id, reportId))
      .limit(1);
    if (existing.length > 0) return;
    
    // Create synthesis job
    await tx.insert(synthesis_jobs).values({
      report_id: reportId,
      status: "queued",
      run_after: new Date(),
    });
  });
}
```

### `packages/worker/src/pg-runner/recovery.ts`

```typescript
export async function recoverStaleJobs(config: WorkerConfig) {
  // Every 30-60 seconds:
  
  // Find source jobs where:
  // status = 'running' AND locked_at < now() - 15 minutes
  const stale = await db.select().from(report_platform_jobs).where(
    and(
      eq(report_platform_jobs.status, "running"),
      lt(report_platform_jobs.locked_at, new Date(Date.now() - config.sourceJobTimeoutMinutes * 60000))
    )
  );
  
  for (const job of stale) {
    if (job.attempt_count < job.max_attempts) {
      // Reset to queued
      await db.update(report_platform_jobs).set({
        status: "queued",
        run_after: new Date(),
        locked_at: null,
        locked_by: null,
        last_error: "Recovered stale running source job",
      }).where(eq(report_platform_jobs.id, job.id));
    } else {
      // Mark failed
      await db.update(report_platform_jobs).set({
        status: "failed",
        stage: "failed",
        last_error: "Max attempts exceeded; stale running job",
        locked_at: null,
        locked_by: null,
      }).where(eq(report_platform_jobs.id, job.id));
      
      // Fan-in check
      await fanInCheck(job.report_id);
    }
  }
}
```

### `packages/worker/src/pg-runner/index.ts`

Main entry point with polling loop:

```typescript
import { db } from "../db";
import { claimSourceJob, claimSynthesisJob } from "./claim";
import { processSourceJob } from "./source-worker";
import { processSynthesisJob } from "./synthesis-worker";
import { recoverStaleJobs } from "./recovery";

const workerId = `${os.hostname()}:${process.pid}:${Math.random().toString(36).slice(2, 8)}`;
const config: WorkerConfig = {
  workerId,
  pollIntervalMs: 1500,
  sourceJobTimeoutMinutes: 15,
  synthesisJobTimeoutMinutes: 30,
};

async function pollSourceJobs() {
  while (true) {
    try {
      const job = await db.transaction(async (tx) => claimSourceJob(tx, workerId));
      if (job) {
        const report = await db.select().from(reports).where(eq(reports.id, job.report_id)).limit(1);
        await processSourceJob(job, report[0], workerId);
      }
    } catch (err) {
      console.error("Source job poll error:", err);
    }
    await new Promise(r => setTimeout(r, config.pollIntervalMs));
  }
}

async function pollSynthesisJobs() {
  while (true) {
    try {
      const job = await db.transaction(async (tx) => claimSynthesisJob(tx, workerId));
      if (job) {
        await processSynthesisJob(job, workerId);
      }
    } catch (err) {
      console.error("Synthesis job poll error:", err);
    }
    await new Promise(r => setTimeout(r, config.pollIntervalMs));
  }
}

async function recover() {
  while (true) {
    try {
      await recoverStaleJobs(config);
    } catch (err) {
      console.error("Recovery error:", err);
    }
    await new Promise(r => setTimeout(r, 30000)); // every 30 seconds
  }
}

async function main() {
  console.log(`Worker ${workerId} starting...`);
  
  // Start all loops in parallel
  await Promise.all([
    pollSourceJobs(),
    pollSynthesisJobs(),
    recover(),
  ]);
}

main().catch(err => {
  console.error("Fatal:", err);
  process.exit(1);
});
```

const readableError = err instanceof Error ? err.message : String(err);

function getStuckReason(job, thresholdSeconds) {
  if (job.status === "queued" && job.attempt_count === 0 && 
      Date.now() - job.created_at > thresholdSeconds * 1000) {
    return "Queued for too long without attempt";
  }
  if (job.status === "running" && job.locked_at &&
      Date.now() - job.locked_at > thresholdSeconds * 1000) {
    return "Running for too long without progress (may be recovered)";
  }
  return null;
}

## 10. Known Risks & Mitigations

| Risk | Severity | Mitigation |
|------|----------|-----------|
| Two workers claim same job | High | Use SELECT ... FOR UPDATE SKIP LOCKED; test with concurrent workers |
| Stuck job hangs forever | High | Implement stale job recovery loop; progress endpoint shows stuck_reason |
| Lost keywords between request and job | Medium | Expand before transaction; store in job payload if needed later |
| Fan-in race (duplicate synth job) | Medium | Advisory lock + unique constraint on (report_id); test idempotency |
| Worker crashes mid-job | Medium | locked_at timeout recovery; logs identify which job + worker |
| Concurrent Inngest + Postgres events | Low | Feature flag ensures only one path active per deployment |
| New reports created while worker down | Low | Jobs stay queued; recovery loop resets after timeout |
| Keyword expansion fails mid-process | Low | Fail before any DB writes; user sees clear error message |

## 12. What's Different from Inngest

| Aspect | Inngest | Postgres |
|--------|---------|----------|
| Event dispatch | API calls inngest.send() | API inserts job rows |
| Job queue | External service (localhost:8288 or cloud) | Postgres table |
| Worker discovery | Inngest routes events to listening workers | Worker polls for queued jobs |
| Observability | Inngest UI shows events + retries | Postgres queries + pipeline_events table |
| Failure modes | 401 missing key, network timeout | DB connection failure, stale job timeout |
| Concurrency | Configured in function definition | Enforced by locking + skip locked |
| Idempotency | Inngest event ID + deduplication | Unique constraints + attempt tracking |
